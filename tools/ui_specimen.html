Accent — interface state only

Amber comes off the RADAR wordmark in the logo. It marks state: what is on, selected, or focused. It is never used for alert severity, so an amber control can never be misread as a warning.

What this palette deliberately excludes

Radar reflectivity and velocity tables, NWS event colors, hurricane categories, outage buckets, spotter report types and sounding traces are data. They keep their own colors and are not themed by these tokens — the interface never borrows a color that means something on the map.
